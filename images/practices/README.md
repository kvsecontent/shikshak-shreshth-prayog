# Practice images · पद्धति चित्र

हर पद्धति की "कक्षा दृश्य" इमेज यहाँ रखें। **फ़ाइल का नाम = पद्धति का ID**, जैसे:

- `s2025-24.jpg` → 2025 के विद्यालय शिक्षक नं. 24 (Tarun Kumar Dash) की पद्धति
- `g03.jpg` → विश्व पद्धति (सिंगापुर CPA)

ID कहाँ मिलेगा: साइट पर किसी पद्धति का **इमेज प्रॉम्प्ट** खोलें, वहाँ "बनी हुई इमेज यहाँ सहेजें" में सही नाम लिखा है (कॉपी बटन के साथ)। पूरी सूची `data/awardees.csv` के `id` कॉलम में भी है।

`.jpg`, `.png`, `.webp` तीनों चलते हैं, लेकिन JPG सबसे हल्की है। ChatGPT की PNG इमेज (2–3 MB) को छोटा करने के लिए उन्हें `images/incoming/` में डालें और चलाएँ:

```bash
bash scripts/add_images.sh
```
